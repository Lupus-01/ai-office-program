# 숏폼 장면표 형식 (make-short.cjs 입력)

영상 하나에 장면표 JSON 하나를 쓴다. 세로 1080×1920, 장면 12개 이하, 길이 합 60초 이하(권장 15~30초).
만들기: `node 보관함/상담사데이터/도구/make-short.cjs <장면표.json>` → 같은 폴더에 `<name>.mp4`와 `미리보기/장면-NN.png`.
화면에는 본문과 볼콩이만 나온다. 홍카페·볼콩이 이름표, "내부 시안", 출처·선정 기준·수집 기준일, 쪽수는 화면에 넣지 않는다(2026-11-17 대표 결정). 기준·기준일은 업무 보고와 유튜브 설명(`유튜브설명.txt`)에 적는다. 영상은 시안이며 외부 채널 게시·업로드는 하지 않는다(법무·상담사 동의 확인 전).

```json
{
  "name": "베리_숏폼_시안1",
  "counselor": { "code": "IT-20230216112800-712", "nick": "베리" },
  "bgm": null,
  "scenes": [
    { "type": "hook", "kicker": "연애·재회 고민", "text": "그 사람 속마음,\n궁금하지 않으세요?", "seconds": 3 },
    { "type": "profile", "title": "베리 선생님", "lines": ["타로 · 신점", "평점 5.0 · 후기 13,934건"], "chips": ["적중", "편안함", "친절함"], "photo": false, "seconds": 4 },
    { "type": "quote", "text": "짧게 줄인 최근 후기 한두 문장", "meta": "11월 15일 후기 · ★5 · 연애", "seconds": 4 },
    { "type": "stats", "title": "최근 3개월", "items": [{ "value": "165건", "label": "새 후기" }, { "value": "100%", "label": "만족도" }], "seconds": 3 },
    { "type": "cta", "text": "홍카페에서\n베리 선생님 만나기", "sub": "홍카페 앱·웹에서 '베리' 검색", "seconds": 3 }
  ]
}
```

- `theme`: 볼콩이(3D)가 있으면 `studio`(파스텔 무대)가 기본. `night`(남보라 밤하늘)·`pastel`도 있다.
- `basis`·`chrome`: `chrome: true`를 줄 때만 위아래 표시와 `basis`(근거·기준일)가 화면에 나온다. 기본은 넣지 않는다.
- `counselor.code`: 수집 원본 파일 이름(프로필 코드). 사진(`photo: true`)을 쓰면 원본의 프로필 사진을 가져온다. 상담사 동의 확인 전에는 시안에서만 쓴다.
- `bgm`: 배경음 mp3 경로(선택). 없으면 무음 소리 트랙을 넣는다. 저작권이 확인된 음원만 쓴다.
- 장면 종류(`type`)
  - `hook`: 첫 3초 질문. `kicker`(작은 머리말), `text`
  - `profile`: `title`, `lines`(2~3줄), `chips`(후기 키워드 3개 정도), `photo`
  - `quote`: 후기 인용. `text`는 한두 문장으로 줄이고 개인 사정(건강·가족·실명·연락처)이 드러나는 후기는 쓰지 않는다. `meta`에 날짜·평점, `note`(작은 덧말)는 필요할 때만
  - `stats`: `title`, `items`([{value, label}] 2~4개)
  - `cta`: 마무리 안내. `text`, `sub`
- `seconds`: 장면 길이(1.5~10초). 글이 많으면 길게, 글자 수는 장면당 60자 안쪽을 권장한다(넘치면 글자 크기가 자동으로 줄어든다).
- 쓰지 않는 표현: "100% 적중"·"무조건" 같은 효과 보장, 다른 상담사·회사 비방, 후기 원문에 없는 내용.

## 진행 캐릭터(볼콩이, 운영팀 마스코트) — 3D, 글과 한 화면으로

장면표(또는 모음표)에 `"host": { "name": "볼콩이" }`만 넣으면 된다. 3D 볼콩이(외곽선 있는 크림색 피규어)가 장면 내용을 **직접 들고** 반응하고, 배경·글꼴·말풍선은 볼콩이 색에 맞춘 `studio` 테마(파스텔 무대, 동글 글꼴 Jua)가 기본이다(2026-11-17 대표: 글과 캐릭터가 따로 놀지 않게).
3D 동작은 장면마다 `character3d.cjs`가 자동으로 만들고 같은 내용이면 다시 쓴다(첫 장면은 몇 초 더 걸림).

| 장면 | 볼콩이 | 화면 글 |
| --- | --- | --- |
| `title`(인트로) | `host: { "pose": "인사", "say": "…" }` 가운데에서 손 흔듦 | `kicker`(분홍 꼬리표), `title`(큰 제목) |
| `rank` | 자동: "TOP n" 팻말을 들고 정면 | `title`(예명, 크게), `sub`(선택) |
| `profile` + `"photo": true` | 자동: 상담사 사진 액자를 들고 웃음 | `title`(예명), `lines`(1줄), `chips`(선택) |
| `quote`(후기) | 자동: 후기 카드(`text`·`meta`)를 들고 감동한 눈으로 내려다봄. `host.expression`으로 `happy` 등 바꿀 수 있음 | `kicker`(예: "○○ 선생님 후기") |
| `cta`(마무리) | `host: { "pose": "하트" 또는 "인사", "say": "…" }` | `text`, `sub`, `brand`(기본 "hongcafe.com", 빈 글자면 숨김) |

- **홍카페 로고**(사이트 머리글 로고, `보관함/상담사데이터/영상/로고/홍카페_로고_full.svg`)가 모든 장면 위쪽 가운데에 작게, `title`·`cta` 장면에는 크게 들어간다(2026-11-17 대표 결정). 빼려면 `"logo": false`. 마무리 `cta`의 `brand` 기본값은 "hongcafe.com".
- 볼콩이는 어깨부터 이어진 팔로 소품 가장자리를 앞에서 쥐고, 인사는 머리 옆에서 손을 흔들고, 하트는 두 손으로 안는다.
- 장면마다 `host.say`(말풍선)를 붙인다. **한 줄 16자 안팎, 두 줄까지**(줄바꿈 `
`). 머리 바로 위에 붙는다.
- 후기 카드 글(`text`)은 **35자 안팎, 세 줄까지**로 줄인다(넘치면 "…"로 잘림). `meta`는 "11월 14일 · ★5"처럼 짧게.
- 자세(`host.pose`): `기본` `인사` `하트` `감동`(두 손 모으고 올려다봄) `웃음`(통통 뛰기) `수줍`. 위치 `host.at`: 기본 `center`, `left`·`right`도 됨. 크기 `host.size`(높이 px).
- **볼콩이 말투(2026-11-17 대표 결정):** "~했대!"로 후기를 전하지 말고, 볼콩이가 후기를 직접 읽고 느낀 마음을 1인칭으로 말한다. 상담사 이름과 후기 속 실제 내용을 붙인다.
  - 좋음: "백범기 선생님은 참 친절하신 거 같아!", "마음이 따뜻해지는 상담을 해주시는구나…"
  - 피함: "친절하대!", "편안해졌대!", 후기에 없는 내용
- 장면표·모음표에 `theme`을 쓰지 않거나 `"studio"`로 둔다(예전 시안의 `"night"`는 지운다).
- 2D 그림으로 하려면 `"host": { "style": "2d", "prefix": "볼콩_" }`(자른그림 폴더), 테마는 `"theme": "night"` 등으로 바꿀 수 있다.
- 미리보기 폴더의 `장면-NN-캐릭터.png`로 글·말풍선·볼콩이가 겹치지 않는지 확인한다.

## 모음 영상(여러 구간 이어 붙이기)

`node 보관함/상담사데이터/도구/make-compilation.cjs <모음표.json>` → 구간마다 영상을 만들고(각 구간은 따로 숏폼으로도 쓸 수 있음) 하나로 이은 `<name>.mp4`와 `유튜브챕터.txt`를 모음표 폴더에 만든다. 구간 영상은 `구간/NN_제목/`에 있다. 장면표가 그대로면 다음 실행 때 다시 만들지 않는다(`--force`로 전부 다시).

```json
{
  "name": "홍카페_상담사_TOP10_시안1",
  "theme": "night",
  "host": { "name": "볼콩이" },
  "bgm": null,
  "parts": [
    { "title": "인트로", "plan": "00_인트로.json" },
    { "title": "10위 연희 선생님", "plan": "10위_연희.json" },
    { "title": "마무리", "plan": "99_마무리.json" }
  ]
}
```

- `theme`·`basis`·`host`는 구간 장면표에 없으면 모음표 값을 쓴다. `bgm`은 모음 영상 전체에 한 번 깐다(구간 장면표의 bgm은 무시).
- 구간 20개, 전체 10분 이하. 구간 하나는 장면표 규칙(12장면·60초 이하)을 따른다. 상담사 구간은 20~30초를 권장한다.
- 순위의 선정 기준과 수집 기준일은 화면에 넣지 않고, 모음표 폴더에 `유튜브설명.txt`(영상 설명 초안: 소개 문단, 선정 기준·기준일, 챕터)로 적고 업무 보고에도 적는다. 순위 근거는 `node 보관함/상담사데이터/도구/top.cjs --top 10 --json <파일>`로 뽑는다(최근 7일 후기 수 기준, 후기 인용 후보 포함).

## 대본 쓰는 법(내용) — 2026-11-17 대표: "캐릭터와 내용에 더 신경"

재료는 `node 보관함/상담사데이터/도구/top.cjs --top 10 --json <파일>`로 뽑는다. 상담사마다 대표 상담분야(`topFields`)·상담스타일(`topStyles`)·최근 후기 분야(`recentFields`)·후기 키워드·서비스 소개 첫 줄(`intro`)·약력(`career`)·**구체적인 후기 후보 8개**(`quotes`, 점수순)가 나온다.

**상담사 한 명 구간(20~25초) 기본 흐름**
1. `rank`(3초): 볼콩이가 팻말을 들고 "N위는 ○○ 선생님이야!" + 그 선생님을 한마디로(대표 분야·스타일 근거). 예: "재회 고민이라면 꼭 만나봐야 할 분이야!"
2. `profile`(5초, 사진): `lines`에 대표 상담분야 2~3개(예: "재회 · 속마음 · 애정"), `chips`에 후기 키워드 3개. 볼콩이는 자료에서 본 사실을 자기 느낌으로: "후기에 '편안해요'가 정말 많네! 마음 놓고 얘기할 수 있겠다"
3. `quote`(6초): 가장 구체적인 후기 하나를 카드로. 볼콩이 반응은 **후기 속 구체적인 내용을 짚어** 자기 마음으로 말한다. 예: 후기 "남친과 화해했어요… 속마음 너무 잘 맞고" → 볼콩이 "화해하셨다니 내 마음까지 놓여!
베리 선생님 정말 고마워"
4. `quote`(6초): 결이 다른 두 번째 후기(예: 첫째가 '재회'면 둘째는 '조언·말투'). 표정도 다르게(`happy` 등).
5. (선택) 마무리 한마디 2~3초: "○○ 선생님, 앞으로도 응원할게!" — 구간마다 같은 문장을 쓰지 않는다.

**볼콩이 말 쓰는 규칙**
- 1인칭으로 느낌을 말한다: 뭉클해, 마음이 놓여, 든든하다, 신기해, 따뜻해진다… "~했대!", "~하대!"처럼 남의 말을 옮기는 꼴은 쓰지 않는다.
- 상담사 이름을 구간마다 한 번 이상 넣는다. 후기 속 구체적인 단어(화해, 타이밍, 솔직한 조언, 카드 뽑기 등)를 하나 이상 짚는다.
- 10명 구간에서 같은 문장·같은 끝맺음("~구나!")을 되풀이하지 않는다. 다 쓴 뒤 말풍선만 모아 읽어 보고 겹치는 표현을 바꾼다.
- 후기에 없는 효과("100% 맞는다", "꼭 재회된다")를 말하지 않는다. 다른 상담사와 비교하지 않는다.
- 말풍선 한 줄 16자 안팎, 두 줄까지. 후기 카드 글은 원문 뜻을 바꾸지 않고 35자 안팎으로 줄인다(이모지·ㅎㅎ·반복 표현은 뺀다).

**후기 고르기**
- `quotes` 점수가 높은 것부터, 상담 내용이나 느낌이 구체적인 후기를 고른다. "감사합니다"만 있는 후기, 같은 말을 되풀이한 후기는 쓰지 않는다.
- 건강·임신·사망·가족사·빚·소송처럼 민감한 사정, 다른 사람(애인 등)의 사생활이 드러나는 부분은 빼거나 다른 후기를 쓴다.
- 화면에 선정 기준·후기 수·평점 같은 숫자는 쓰지 않는다(기준·기준일은 `유튜브설명.txt`와 보고에).

**검수(영상제작담당)**
- 영상을 만든 뒤 구간마다 `미리보기/장면-NN-캐릭터.png`를 **모두** 열어 본다: 말풍선·제목·카드 글이 넘치거나 잘리지 않는지, 볼콩이 팔·손이 잘리거나 떠 있지 않은지, 글자 굵기가 장면마다 같은지.
- 문제가 있으면 장면표를 고쳐 그 구간만 다시 만든다(모음 영상 도구는 바뀐 구간만 다시 만든다).
