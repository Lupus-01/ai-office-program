# 숏폼 장면표 형식 (make-short.cjs 입력)

영상 하나에 장면표 JSON 하나를 쓴다. 세로 1080×1920, 장면 12개 이하, 길이 합 60초 이하(권장 15~30초).
만들기: `node 보관함/상담사데이터/도구/make-short.cjs <장면표.json>` → 같은 폴더에 `<name>.mp4`와 `미리보기/장면-NN.png`.
화면 오른쪽 위에 "내부 시안" 표시가 늘 들어간다. 외부 채널 게시·업로드는 하지 않는다(법무·상담사 동의 확인 전).

```json
{
  "name": "베리_숏폼_시안1",
  "theme": "night",
  "basis": "홍카페 공개 프로필 · 2026-11-16 수집 기준",
  "counselor": { "code": "IT-20230216112800-712", "nick": "베리" },
  "bgm": null,
  "scenes": [
    { "type": "hook", "kicker": "연애·재회 고민", "text": "그 사람 속마음,\n궁금하지 않으세요?", "seconds": 3 },
    { "type": "profile", "title": "베리 선생님", "lines": ["타로 · 신점", "평점 5.0 · 후기 13,934건"], "chips": ["적중", "편안함", "친절함"], "photo": false, "seconds": 4 },
    { "type": "quote", "text": "짧게 줄인 최근 후기 한두 문장", "meta": "11월 15일 후기 · ★5 · 연애", "seconds": 4 },
    { "type": "stats", "title": "최근 3개월", "items": [{ "value": "165건", "label": "새 후기" }, { "value": "100%", "label": "만족도" }], "seconds": 3 },
    { "type": "cta", "text": "홍카페에서\n베리 선생님 만나기", "sub": "홍카페 앱·웹에서 '베리' 검색", "seconds": 3 }
  ]
}
```

- `theme`: `night`(남보라 밤하늘, 기본) 또는 `pastel`.
- `basis`: 화면 아래 왼쪽에 나오는 근거·기준일. 숫자(평점·후기 수)를 쓰면 수집 기준일을 꼭 적는다.
- `counselor.code`: 수집 원본 파일 이름(프로필 코드). 사진(`photo: true`)을 쓰면 원본의 프로필 사진을 가져온다. 상담사 동의 확인 전에는 내부 시안에서만 쓴다.
- `bgm`: 배경음 mp3 경로(선택). 없으면 무음 소리 트랙을 넣는다. 저작권이 확인된 음원만 쓴다.
- 장면 종류(`type`)
  - `hook`: 첫 3초 질문. `kicker`(작은 머리말), `text`
  - `profile`: `title`, `lines`(2~3줄), `chips`(후기 키워드 3개 정도), `photo`
  - `quote`: 후기 인용. `text`는 한두 문장으로 줄이고 개인 사정(건강·가족·실명·연락처)이 드러나는 후기는 쓰지 않는다. `meta`에 날짜·평점·분야, `note`는 기본 "실제 후기 일부를 줄여 옮김"
  - `stats`: `title`, `items`([{value, label}] 2~4개)
  - `cta`: 마무리 안내. `text`, `sub`
- `seconds`: 장면 길이(1.5~10초). 글이 많으면 길게, 글자 수는 장면당 60자 안쪽을 권장한다(넘치면 글자 크기가 자동으로 줄어든다).
- 쓰지 않는 표현: "100% 적중"·"무조건" 같은 효과 보장, 다른 상담사·회사 비방, 후기 원문에 없는 내용.

## 진행 캐릭터(볼콩이, 운영팀 마스코트)

장면표(또는 모음표)에 `"host": { "name": "볼콩이", "prefix": "볼콩_" }`를 넣고, 장면마다 `host`를 붙이면 캐릭터가 나온다.
그림: `보관함/상담사데이터/영상/캐릭터/자른그림/볼콩_<자세>.png` — 자세: `기본` `옆` `인사`(손 흔듦) `하트` `팻말`(빈 판을 든 모습) `앉음`, 얼굴만: `웃음` `반짝` `수줍`.

```json
{ "type": "quote", "text": "…", "meta": "…", "seconds": 4,
  "host": { "pose": "하트", "at": "left", "say": "마음이 편해졌대! 다행이다" } }
```

- `at`: `left`·`right`(화면 아래쪽 왼쪽·오른쪽, 기본 높이 430px), `center`(가운데 크게 640px, 인트로·마무리용). `size`로 높이(px)를 바꾼다.
- `say`: 말풍선(캐릭터 위). 30자 안팎, 볼콩이 말투(친근한 반말, "~야", "~했대!")로 짧게. 없으면 말풍선 없이 캐릭터만.
- 움직임: 들어올 때 옆에서 미끄러져(가운데는 아래에서 튀어) 들어오고, 그 뒤로 통통 튄다. 캐릭터가 있는 장면은 본문이 위로 올라가므로 글을 짧게 쓴다.
- 미리보기 폴더에 캐릭터까지 얹은 `장면-NN-캐릭터.png`가 함께 생긴다(영상과 같은 자리).

추가 장면 종류
- `title`: 큰 제목. `kicker`, `title`, `sub`(선정 기준·기준일 등). 인트로에 쓴다.
- `rank`: 볼콩이가 든 팻말에 순위를 쓴다. `rank`("1"), `label`(기본 "TOP"), `title`(예명), `sub`(선정 근거, 예: "최근 7일 후기 116건"). 캐릭터 그림이 팻말 안에 들어가므로 `host`는 붙이지 않는다.

## 모음 영상(여러 구간 이어 붙이기)

`node 보관함/상담사데이터/도구/make-compilation.cjs <모음표.json>` → 구간마다 영상을 만들고(각 구간은 따로 숏폼으로도 쓸 수 있음) 하나로 이은 `<name>.mp4`와 `유튜브챕터.txt`를 모음표 폴더에 만든다. 구간 영상은 `구간/NN_제목/`에 있다. 장면표가 그대로면 다음 실행 때 다시 만들지 않는다(`--force`로 전부 다시).

```json
{
  "name": "홍카페_상담사_TOP10_시안1",
  "theme": "night",
  "basis": "홍카페 공개 프로필 · 2026-11-16 수집 기준 · 최근 7일 후기 수 기준",
  "host": { "name": "볼콩이", "prefix": "볼콩_" },
  "bgm": null,
  "parts": [
    { "title": "인트로", "plan": "00_인트로.json" },
    { "title": "10위 연희 선생님", "plan": "10위_연희.json" },
    { "title": "마무리", "plan": "99_마무리.json" }
  ]
}
```

- `theme`·`basis`·`host`는 구간 장면표에 없으면 모음표 값을 쓴다. `bgm`은 모음 영상 전체에 한 번 깐다(구간 장면표의 bgm은 무시).
- 구간 20개, 전체 10분 이하. 구간 하나는 장면표 규칙(12장면·60초 이하)을 따른다. 상담사 구간은 20~30초를 권장한다.
- 순위를 말할 때는 선정 기준과 수집 기준일을 인트로와 `basis`에 밝힌다. 순위 근거는 `node 보관함/상담사데이터/도구/top.cjs --top 10 --json <파일>`로 뽑는다(최근 7일 후기 수 기준, 후기 인용 후보 포함).
