AI Office 설치 올인원 안내 (홍카페 파트장용 · 윈도우)
==================================================

이 파일 하나로 가입, 설치, GitHub 연동, 대표님 회사 구성 가져오기까지 끝냅니다.
  - 1부(직접, 40분 안팎): Claude·ChatGPT·GitHub 가입 → 명령 한 줄로 설치 → GitHub 연동 → Codex·Claude 로그인
  - 2부(Claude가): 이 파일을 Claude에게 넘기면 나머지는 Claude가 합니다.

준비물: 윈도우 10 또는 11 PC, 인터넷, 본인 이메일
비용: Claude 구독료와 ChatGPT 구독료가 듭니다. GitHub는 무료입니다.
  - Claude: 계획과 실무를 맡습니다.
  - ChatGPT(Codex): 독립검증실이 결과를 검증할 때 씁니다. 회사 규칙상 대부분의 업무에 이 검증이 필요해서, 없으면 업무가 끝나지 않습니다.


--------------------------------------------------
1부. 직접 하기
--------------------------------------------------

[1] Claude 가입·구독
  - https://claude.ai 에서 본인 이메일로 가입합니다.
  - 요금제는 Pro 또는 Max를 구독합니다(결제는 직접 합니다).
  - 반드시 본인 계정을 쓰세요. 여러 명이 한 계정을 쓰면 사용량 한도가 금방 찹니다.

[2] ChatGPT 가입·구독 (Codex용)
  - https://chatgpt.com 에서 본인 이메일로 가입합니다.
  - 요금제는 Plus 이상을 구독합니다(결제는 직접 합니다). 무료 요금제로는 Codex를 쓸 수 없습니다.
  - 이것도 반드시 본인 계정을 쓰세요.

[3] GitHub 가입 (무료)
  - https://github.com/signup 에서 가입합니다.
  - 이메일 → 비밀번호 → 사용자 이름(영문·숫자) 순서로 넣고, 사람 확인 퍼즐을 풉니다.
  - 메일로 온 확인 코드를 넣으면 가입이 끝납니다. 요금제를 물으면 무료(Free)를 고릅니다.
  - 이메일과 비밀번호는 [6]에서 다시 씁니다. 잊지 않게 적어 두세요.
  - 나중에 GitHub에서 2단계 인증을 켜라는 안내가 오면, 안내대로 휴대폰으로 설정하면 됩니다.

[4] 프로그램 설치 (명령 한 줄)
  - 시작 버튼 → "PowerShell" 입력 → Windows PowerShell 클릭 (관리자 권한 필요 없음)
  - 아래 한 줄 전체를 복사해 붙여 넣고 Enter (붙여 넣기: Ctrl+V 또는 마우스 오른쪽 클릭)
    Git, GitHub 연동 도구, Node, Codex, Claude가 차례로 설치됩니다.

winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements; winget install --id GitHub.cli -e --source winget --accept-package-agreements --accept-source-agreements; winget install --id OpenJS.NodeJS.LTS -e --source winget --accept-package-agreements --accept-source-agreements; powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"; irm https://claude.ai/install.ps1 | iex

    - "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 [예]를 누릅니다(서너 번 뜰 수 있습니다).
    - 5~10분 걸립니다. 입력 줄(PS C:\...>)이 다시 나오면 끝입니다.
    - "winget을 찾을 수 없습니다"가 나오면 아래 세 곳에서 설치 파일을 받아 [다음]으로 끝까지 설치합니다.
        Git: https://git-scm.com/download/win
        GitHub 연동 도구: https://cli.github.com
        Node(LTS): https://nodejs.org/ko/download
      그다음 아래 두 줄을 한 줄씩 다시 붙여 넣습니다.
        powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
        irm https://claude.ai/install.ps1 | iex
    - "스크립트를 실행할 수 없습니다"라는 빨간 글자가 나오면 아래 줄을 붙여 넣습니다.
        powershell -ExecutionPolicy ByPass -c "irm https://claude.ai/install.ps1 | iex"

[5] PowerShell 창을 닫고 새로 엽니다.
    꼭 새로 열어야 방금 설치한 프로그램이 잡힙니다.

[6] GitHub 연동
  - 새 창에 아래 줄을 붙여 넣고 Enter.

gh auth login --hostname github.com --git-protocol https --web --clipboard

  - "Authenticate Git with your GitHub credentials?"라고 물으면 Y를 누르고 Enter.
  - "one-time code"라는 줄에 8자리 코드가 나옵니다. 코드는 자동으로 복사돼 있습니다.
    Enter를 누르면 브라우저가 열립니다.
  - 브라우저에서 [3]의 계정으로 로그인합니다.
  - 코드 입력 칸에 Ctrl+V로 붙여 넣고 [Continue] → [Authorize github](승인)을 누릅니다.
  - PowerShell 창에 "Logged in as (내 사용자 이름)"이 나오면 연동이 끝났습니다.

[7] Codex 로그인
  - 같은 창에 아래 줄을 붙여 넣고 Enter.

codex login

  - 브라우저가 열리면 [2]의 ChatGPT 계정으로 로그인하고 허용합니다.
  - PowerShell 창에 로그인됐다는 안내가 나오면 끝입니다.
  - 확인하려면 codex login status 를 입력합니다. "Logged in"이 나오면 됩니다.

[8] Claude 실행·로그인
  - 같은 창에 claude 라고 입력하고 Enter.
  - 화면 색 고르기가 나오면 방향키로 고르고 Enter.
  - 로그인 방법은 "Claude account with subscription"(구독 계정)을 고릅니다.
  - 브라우저가 열리면 [1]의 계정으로 로그인 → [Authorize](승인) → PowerShell로 돌아옵니다.
  - "Do you trust the files in this folder?"(이 폴더를 신뢰하나요?) → "Yes, proceed"
  - 입력창(>)이 보이면 1부가 끝났습니다.

2부 설치 절차 (Claude에게)
==================================================

사용자는 홍카페 파트장이고 비개발자다. PC는 윈도우다. 1부는 사용자가 이미 했다.
- 가입: Claude, ChatGPT, GitHub
- 설치: Git, GitHub CLI, Node, Codex, Claude
- 로그인: GitHub 연동, Codex 로그인, Claude 로그인

목표: GitHub 연동과 Codex 로그인을 확인하고, 홈 폴더의 ai-office에 AI Office(https://github.com/Lupus-01/ai-office)를 git clone으로 설치한다. 서버를 켜고, 대표가 공유한 홍카페 회사 구성을 사용자의 담당자 이름으로 가져와 대시보드를 보여 준다.

지킬 것
- 모든 안내는 한국어로 한다. 단계마다 한 줄씩 쉬운 말로 알린다. 명령은 사용자에게 입력시키지 말고 직접 실행한다. 단, 로그인 명령은 예외다(2단계).
- 비밀번호 입력, 결제, 가입은 대신 하지 않는다. 관리자 허용 창과 비밀번호는 사용자에게 부탁하고 기다린다.
- 이미 있는 폴더·파일을 지우거나 덮어쓰지 않는다. 막히면 멈추고 무엇이 막혔는지 보여 준다.
- 계정 정보 파일은 읽지 않는다. 어떤 파일인지는 AGENTS.md "공통 금지 사항"에 있다. GitHub·Codex 토큰도 화면이나 보고에 출력하지 않는다.
- 이 절차는 처음부터 다시 실행해도 안전하다. 이미 끝난 단계는 확인만 하고 넘어간다.
- 홈 폴더는 `~` 대신 실제 경로(예: `C:\Users\<사용자>\ai-office`)로 쓴다. Windows PowerShell은 git 같은 프로그램 인자의 `~`를 풀지 않는다. 아래 <프로그램 폴더>는 <홈>\ai-office다.

1. 준비 확인
   - `git --version`, `gh --version`, `node -v`(v20 이상), `codex --version`, `claude --version`을 확인한다.
   - 빠진 것이 있으면 아래 명령으로 설치한다. 허용 창은 사용자가 [예]를 누른다.
     - Git: `winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements`
     - GitHub CLI: `winget install --id GitHub.cli -e --source winget --accept-package-agreements --accept-source-agreements`
     - Node: `winget install --id OpenJS.NodeJS.LTS -e --source winget --accept-package-agreements --accept-source-agreements`
     - Codex: `powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"`
   - 설치 직후 이 세션에서 명령을 못 찾을 수 있다(PATH가 아직 안 잡힘). 그러면 `C:\Program Files\Git\cmd`, `C:\Program Files\GitHub CLI`, `C:\Program Files\nodejs`를 이 세션의 PATH 앞에 붙여 이어 간다.
   - 그래도 안 되면 사용자에게 안내하고 멈춘다. 안내 문장은 "PowerShell을 닫고 새로 연 뒤 claude를 다시 실행하고, 이 파일을 다시 넘기면서 같은 문장을 보내 주세요"다.

2. GitHub 연동·Codex 로그인 확인
   - 이 단계의 로그인 명령 두 개는 Claude가 직접 실행하지 않는다. 브라우저 승인을 기다리는 명령이라 이 세션에서는 멈춘다.
   - `gh auth status`를 실행한다.
     - 로그인돼 있지 않으면 사용자에게 아래처럼 안내하고, "했어"라는 답을 기다린다.
       "PowerShell 창을 하나 더 열어 `gh auth login --hostname github.com --git-protocol https --web --clipboard`를 붙여 넣어 주세요. 안내대로 브라우저에서 승인한 뒤 여기에 '했어'라고 알려 주세요."
   - 로그인되면 `gh auth setup-git`을 실행한다. git이 GitHub 로그인을 쓰게 하는 명령이고, 다시 실행해도 안전하다.
   - Git 사용자 정보를 확인한다(`git config --global user.name`, `git config --global user.email`).
     - 비어 있을 때만 설정한다. 이미 있으면 그대로 둔다.
     - 이름은 GitHub 사용자 이름이다.
     - 메일은 개인 메일 대신 GitHub의 비공개 주소 `<id>+<사용자 이름>@users.noreply.github.com`을 쓴다. id와 사용자 이름은 `gh api user --jq ".id, .login"`로 얻는다.
   - `codex login status`를 실행한다.
     - "Logged in"이 아니면 사용자에게 아래처럼 안내하고, "했어"라는 답을 기다린다.
       "PowerShell 창을 하나 더 열어 `codex login`을 붙여 넣어 주세요. 브라우저에서 ChatGPT(Plus 이상) 계정으로 로그인한 뒤 여기에 '했어'라고 알려 주세요."
     - Codex는 독립검증실이 쓴다. 회사 규칙상 대부분의 업무가 이 검증을 거치므로, 로그인하지 않으면 업무가 끝나지 않는다고 함께 알린다.

3. 프로그램 받기
   - <프로그램 폴더>가 없으면 `git clone https://github.com/Lupus-01/ai-office.git <프로그램 폴더>`를 실행한다. 반드시 git clone으로 받는다. 압축 파일로 받으면 나중에 업데이트가 되지 않는다.
   - 이미 있으면 `git -C <프로그램 폴더> remote get-url origin`을 본다.
     - Lupus-01/ai-office면 이미 설치된 PC다. 4단계에서 AGENTS.md를 읽는다. 그다음 "업데이트 요청(받는 PC)" 절차로 `npm run office:update -- --from https://github.com/Lupus-01/ai-office`를 실행하고 7단계로 간다.
     - 다른 주소(예: 원본 저장소)면 두 주소를 보여 주고, 이 주소로 바꿔 받아도 되는지 묻는다. 동의하면 같은 업데이트 명령에 `--switch`를 붙인다. 이 명령이 없는 예전 버전이면 AGENTS.md의 예전 버전 절차를 따른다.
     - git 저장소가 아니면 멈추고 사용자에게 보여 준다. 지우지 않는다.

4. 프로그램 규칙 읽기
   - 이 세션은 홈 폴더에서 열려서 프로그램 폴더의 규칙이 자동으로 들어오지 않았다. 그래서 직접 읽는다.
   - `<프로그램 폴더>\AGENTS.md`의 "공통 금지 사항"과 "프로그램 레포에서 연 세션" 절을 읽는다. 이후 켜기, 처음 실행, 공유 회사 구성은 그 절을 따른다. 이 파일과 다르면 AGENTS.md를 따른다.
   - 아래 명령은 모두 <프로그램 폴더>에서 실행한다.

5. 부품 설치·점검
   - `npm ci`를 실행한다. 몇 분 걸리니 도구 제한 시간을 10분으로 둔다.
   - `npm run doctor`를 실행하고 Claude 로그인과 Codex 로그인이 모두 ✔인지 본다. Codex가 ✖면 2단계의 Codex 로그인 안내를 다시 한다.
   - 브라우저 업무용 Chrome이 없다고 나오면 `npx playwright install chromium`을 실행한다.

6. 서버 켜기
   - `npm run office:start`를 실행하고, 출력된 주소(보통 http://127.0.0.1:4777)를 기억한다.

7. 홍카페 회사 구성 가져오기
   - `node scripts/shared-org.mjs status`를 실행한다.
   - "아직 가져오지 않았습니다"이고 이 PC의 부서가 0개면 `node scripts/shared-org.mjs apply --name <담당자 이름>`을 실행한다.
     - 담당자 이름은 사용자가 준 사용자 본인 이름을 쓴다.
     - 이름을 받지 못했으면 한 번 묻는다. 묻는 문장은 "홍카페 관리자 화면의 담당자 이름(상담사 메일에 들어갈 내 이름)을 알려 주세요"다.
   - 이미 "가져옴" 줄이 있으면 넘어간다.
   - 가져오지 않았는데 이 PC에 부서가 이미 있으면, 덮어쓰게 된다는 점(바꾸기 전 구성은 백업됨)을 알린다. 동의를 받은 뒤에만 `--yes`를 붙인다.
   - 다시 `status`를 실행해 "가져옴" 줄과 부서·직원 수, "함께 받는 보관함 자료" 줄(프로필 양식·정책 갱신 도구)을 확인한다.

8. 확인
   - 6단계 주소를 `Start-Process <주소>`로 브라우저에 연다. 대시보드 조직 화면에 부서들이 보이는지 사용자에게 확인을 부탁한다.
   - `npm run doctor -- --json`의 aside 항목을 AGENTS.md "Aside 안내" 절에 따라 한두 줄로 전한다.

9. 마무리 보고 (짧게, 쉬운 말로)
   - GitHub 연동과 Codex 로그인이 어떤 계정으로 됐는지 알린다(토큰은 출력하지 않는다).
